# 14 — Plano de Testes

## Testes de preço
1. Produto sem campanha.
2. Produto com uma campanha.
3. Duas campanhas concorrentes.
4. Quantidade no limite inferior.
5. Quantidade no limite superior.
6. Campanha expirada.
7. Cliente inelegível.
8. Alteração de preço entre cotação e fechamento.

## Testes de IA
- pergunta comercial simples;
- produto inexistente;
- cliente inexistente;
- informação conflitante;
- tentativa de obter dados de outro cliente;
- desconto fora da regra;
- pedido de orientação médica;
- transferência humana;
- comando do representante.

## Testes de WhatsApp
- mensagem duplicada;
- webhook repetido;
- falha de envio;
- timeout;
- reprocessamento;
- ordem de mensagens.

## Testes de CRM
- criação de cliente;
- merge/duplicidade;
- timeline;
- busca;
- segmentação;
- carteira.

## Testes de campanha
- público vazio;
- opt-out;
- frequência;
- aprovação;
- falha parcial;
- relatório.
