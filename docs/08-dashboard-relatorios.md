# 08 — Dashboard e Relatórios

## Dashboard principal
- vendas hoje/semana/mês
- comparação com período anterior
- meta e atingimento
- ticket médio
- pedidos
- cotações
- conversão
- clientes ativos/inativos
- oportunidades
- follow-ups atrasados

## Relatórios
### Clientes
- maiores clientes
- clientes inativos
- clientes em risco
- novos clientes
- crescimento

### Produtos
- mais vendidos
- crescimento
- queda
- margem quando disponível
- produtos frequentemente comprados juntos

### Funil
- novos contatos
- oportunidades
- cotações
- negociações
- pedidos
- conversão por etapa

### Campanhas
- enviados
- entregues
- respostas
- oportunidades
- pedidos
- receita atribuída quando possível

## IA analítica
Perguntas como:
- “Quanto vendi este mês?”
- “Quem está parado?”
- “Quem tem maior chance de reposição?”
- “Onde estou perdendo vendas?”
- “Qual produto cresceu mais?”

Respostas devem mostrar período e critérios utilizados.
