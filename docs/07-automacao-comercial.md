# 07 — Automação Comercial

## Gatilhos
- cliente sem compra há X dias
- próxima reposição estimada
- orçamento sem resposta
- pedido entregue
- oportunidade parada
- cliente VIP sem contato
- campanha iniciada
- aniversário/data comercial quando aplicável
- meta próxima/abaixo

## Ações
- criar tarefa
- alertar representante
- iniciar follow-up
- preparar mensagem
- solicitar aprovação
- enviar comunicação autorizada
- atualizar segmento
- criar oportunidade

## Rotinas diárias
### Resumo do representante
- vendas
- oportunidades
- follow-ups
- clientes em risco
- reposições
- orçamentos sem resposta
- campanhas

### Lista diária de contatos
Gerar uma fila priorizada em vez de disparar mensagens indiscriminadamente.

## Recuperação de clientes
Detectar padrão histórico e sugerir abordagem. Registrar resultado para melhorar futuras recomendações.

## Reposição
Estimar próxima compra usando histórico; nunca afirmar necessidade como fato. Usar linguagem de oportunidade/previsão.
