# 11 — Fluxos Principais

## 1. Cotação
Cliente → pergunta produto → IA consulta produto → consulta condição → responde preço → cliente informa quantidade → recalcula → valida → apresenta total → cliente confirma → cria pedido ou envia para aprovação.

## 2. Campanha por quantidade
Representante cadastra campanha → sistema valida datas/regras → agente consulta campanha → cliente pergunta preço → agente identifica quantidade → aplica condição → revalida no fechamento.

## 3. Follow-up
Orçamento criado → cliente não responde → regra de prazo dispara → sistema cria tarefa → representante aprova ou automação executa → resultado registrado.

## 4. Cliente inativo
Regra identifica queda → cria alerta → agente explica motivo/padrão → representante autoriza contato → mensagem enviada → resposta gera oportunidade.

## 5. Reposição
Histórico detecta padrão → sistema estima janela → alerta representante → representante autoriza contato → conversa iniciada → pedido pode ser criado.

## 6. Comando do representante
Representante envia comando → autenticação/identificação → agente interpreta → consulta ferramentas → se ação sensível, pede aprovação → executa → confirma resultado.

## 7. Transferência humana
Cliente solicita pessoa/assunto sensível → IA pausa → representante é notificado → humano assume → encerramento permite retomada.
