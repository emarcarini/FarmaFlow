# 03 — CRM

## Cadastro do cliente
Campos sugeridos:
- nome
- empresa
- telefone/WhatsApp
- e-mail
- documento quando legalmente necessário
- cidade/UF
- endereço
- segmento
- representante responsável
- classificação A/B/C
- potencial
- status
- tags
- observações
- consentimentos/preferências de comunicação

## Timeline
Tudo deve aparecer em ordem cronológica:
- mensagens
- chamadas/notas manuais
- cotações
- pedidos
- alterações de condição
- tarefas
- campanhas
- respostas
- transferências para humano

## Segmentação automática
- ativo
- novo
- inativo
- VIP
- em crescimento
- em risco
- potencial
- sem compra há X dias
- comprou produto X
- não comprou produto Y
- frequência de compra alta/baixa

## Score comercial
Criar score configurável usando, quando disponível:
- recência
- frequência
- valor comprado
- tendência
- potencial
- interação recente
- oportunidade aberta

O score deve ser explicável no painel; não mostrar apenas um número sem motivo.

## Carteira
O representante deve conseguir visualizar:
- clientes prioritários hoje
- clientes em risco
- clientes para reposição
- oportunidades abertas
- follow-ups atrasados
- cotações sem resposta
