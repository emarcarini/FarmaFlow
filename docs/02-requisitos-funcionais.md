# 02 — Requisitos Funcionais

## Atendimento
- Receber e enviar mensagens pelo WhatsApp.
- Identificar cliente pelo telefone.
- Associar conversa ao cliente/empresa.
- Manter histórico completo.
- Responder dúvidas comerciais.
- Consultar catálogo, preço, campanha e disponibilidade.
- Criar cotação.
- Conduzir fechamento dentro das regras.
- Transferir para humano quando necessário.
- Registrar automaticamente intenção, oportunidade e follow-up quando possível.
